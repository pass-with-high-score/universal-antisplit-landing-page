# Universal Anti-Split Landing Page

The official website and interactive web inspector for **Universal Anti-Split** (`https://antisplit.pwhs.app`).

## Features
- **Modern Responsive Design:** Built with Next.js 16 (Turbopack), React 19, and Tailwind CSS v4.
- **Client-Side Split Inspector:** In-browser inspection of XAPK, APKM, APKS, and ZIP packages without uploading files to any server.
- **SEO & Social Optimization:** Dynamic Sitemap, Robots.txt, OpenGraph, and Twitter Cards.
- **PWHS Ecosystem Integration:** Direct links with Universal Installer, BlockAds Android, and GitHub releases.

## Getting Started

Run the development server:

```bash
bun install
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
